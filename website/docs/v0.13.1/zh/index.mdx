# A3S Flow 0.13.1

`v0.13.1` 发布于 2026 年 8 月 15 日，是 1.0 之前最后一个正式发布版本。这个快照只说明该标签中存在的行为，代码示例固定依赖 `0.13.1`。

## 这一版能做什么

| 范围       | 0.13.1 契约                                         |
| ---------- | --------------------------------------------------- |
| 持久执行   | 单步骤、并发步骤批次、固定延迟重试、定时等待和 Hook |
| 停止控制   | 清理式取消、立即取消、超时和主机关闭终态            |
| 外部关联   | 持久进度和由宿主管理的子操作引用                    |
| 运行发布   | `RuntimeBuildId` 准入和精确任务路由                 |
| 存储       | 内存、JSONL、SQLite 和 PostgreSQL                   |
| 任务       | Boot 0.2 任务管理与内置队列                         |
| 观察       | 提交后观察者、事件映射和本地审计日志                |
| TypeScript | 可安装编译器、依赖清单模式和原生 JSON 调用协议      |

这一版的工作流决定仍由 Rust `FlowRuntime` 主持。TypeScript 是可选的原生运行时适配器，事件历史、Worker 和调度继续由 Rust 宿主管理。

## 0.13.1 的发布重点

这一版正式发布了 `a3s-flow-native-compiler`。编译器使用 Bun 生成本机可执行制品，并新增 `NativeTsDependencyMode::CompilerManifest`。

清单模式会把完整源码依赖图、配置文件和编译后端身份纳入制品身份。冷编译前后都重新扫描依赖，文件集合、内容或后端变化时拒绝发布临时制品。

Windows 制品使用 `.exe` 文件名，源码指纹读取使用有界堆缓冲。真实 Bun 编译、缓存与执行测试在 Linux 和 Windows 发布流程中运行。

## 与 1.0 文档的边界

0.13.1 没有 1.0 中新增的第一类命名信号、第一类子工作流、续段、补丁标记和工作流图编译接口。指数退避也尚未加入，`RetryPolicy` 只提供不重试和固定延迟。

不要把 1.0 页面中的命令复制到 0.13.1 项目。切换顶部版本后，导航会只显示这个发布快照的页面。
