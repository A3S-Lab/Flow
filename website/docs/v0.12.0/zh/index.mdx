# A3S Flow 0.12.0

`v0.12.0` 发布于 2026 年 8 月 10 日。这个版本的发布边界是把可选任务管理升级到 `a3s-boot 0.2.0`，把 SQLite 和 PostgreSQL 持久化升级到 `a3s-orm 0.3.0`。

本快照只使用标签 `v0.12.0` 中已经存在的接口。

## 可用能力

| 范围       | 0.12.0 契约                                     |
| ---------- | ----------------------------------------------- |
| 工作流     | 事件重放、单步骤、并发步骤批次和固定延迟重试    |
| 暂停       | UTC 定时等待与外部 Hook                         |
| 停止       | 清理式取消、立即取消、超时和主机关闭终态        |
| 控制面     | 持久进度、外部子操作引用和运行检查              |
| 发布       | `RuntimeBuildId` 准入与精确任务路由             |
| 存储       | 内存、JSONL、SQLite 和 PostgreSQL               |
| 任务       | Boot 0.2 管理器、内存、JSONL 和 PostgreSQL 队列 |
| TypeScript | 由宿主提供编译器的原生运行时适配器              |

## 0.12.0 的依赖边界

打开 `sqlite` 或 `postgres` 功能时，Flow 使用 ORM 0.3 的执行器、事务、行解码和带校验和迁移。打开 `boot` 时，任务管理适配器使用 Boot 0.2 的队列接口。

升级到 0.12.0 时，这两组可选依赖应一起锁定。应用的直接 Boot 或 ORM 依赖若仍固定旧版本，Cargo 可能同时解析两套类型，导致构造器和 Trait 类型不匹配。

## 原生 TypeScript 的范围

0.12.0 已有 `NativeTsRuntime`、原生 JSON 协议、制品缓存、输出上限、超时和预检。它要求宿主提供符合 `compile <entrypoint> -o <artifact>` 形状的编译器可执行文件。

这一版没有随 crate 发布可安装编译器，也没有编译器依赖清单协议。源码身份只覆盖入口文件与工作流部署身份。导入文件、锁文件或 TypeScript 配置变化时，宿主必须更新 `WorkflowSpec.version`。

## 与后续版本的边界

- 0.13.1 增加随包编译器和完整依赖清单模式。
- 1.0 增加命名信号、第一类子工作流、续段、补丁标记和图文档编译。
- 0.12.0 的 `RetryPolicy` 只支持不重试和固定延迟，没有指数退避。

顶部版本切换会保留相同页面主题，但每个版本只展示自己的接口。
