# Persistence

All stores implement `FlowEventStore`. The engine uses expected-sequence appends, run listing, scheduling indexes, active-hook queries, and retention operations through that contract.

## Store selection

| Store                 | Feature    | Intended use                                 |
| --------------------- | ---------- | -------------------------------------------- |
| `InMemoryEventStore`  | built in   | unit tests and short-lived processes         |
| `LocalFileEventStore` | built in   | local durable JSONL history and development  |
| `SqliteEventStore`    | `sqlite`   | one-node durable hosts and embedded products |
| `PostgresEventStore`  | `postgres` | shared production hosts and multiple workers |

## SQLite

Enable the feature and open a database path:

```toml
a3s-flow = { version = "=1.0.0", features = ["sqlite"] }
```

```rust
use a3s_flow::SqliteEventStore;
use std::sync::Arc;

let store = Arc::new(SqliteEventStore::open("flow.db").await?);
let engine = a3s_flow::FlowEngine::new(store, runtime);
```

SQLite is appropriate when one process owns the database file. Keep the file on local durable storage and include it in backup policy.

## PostgreSQL

The PostgreSQL feature uses canonical A3S ORM migrations. Migration authority is separate from serving authority.

```toml
a3s-flow = { version = "=1.0.0", features = ["postgres"] }
```

Run `migrate_postgres_flow` during an explicit migration phase before starting workers. Serving processes should not race to mutate schema at startup.

## Retention

Retention closes eligible history under a `FlowHistoryRetentionPolicy`, records tombstones, and respects active holds. A host must keep legal, audit, and recovery requirements outside the pruning loop.

Test retention against copied production history before enabling deletion in a live environment.

## Store contract

Custom stores must preserve atomic expected-sequence append behavior. A store that allows two writers to commit the same next sequence breaks the engine's durable decision model.
