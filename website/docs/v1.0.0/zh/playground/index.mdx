# 工作流 Playground

这页使用当前版本的节点清单、端口定义、配置表单和图编译器。画布里的节点数据可以直接组成 Flow 工作流文档，页面没有维护另一套示例字段。你可以先改动内置流程，确认节点之间怎样连接，再把生成的 DSL 交给 CLI 或宿主编辑器继续处理。

## 完成一次编辑

从左侧节点库点击节点时，新节点会放在当前画布中心。桌面端也可以直接拖动节点库中的条目，再在画布目标位置松开。节点卡片可以自由移动，输出端口可以拉线到类型兼容的输入端口。选择节点后，右侧配置区会打开对应 manifest 生成的表单，名称、说明、重试策略、表达式和运行参数会立即写回画布状态。

工具栏可以删除当前选中的节点或连线，也可以恢复内置示例。删除容器时，容器内部的节点和连线会一并清理。键盘用户可以用 Tab 移动到节点库、画布节点、缩放按钮和配置控件，选中画布元素后可以使用 Delete 或 Backspace 删除。

## 检查图和配置

校验页签同时显示图编译结果与节点配置问题。图编译器会检查缺失节点、跨作用域连线、重复标识、环路和容器结构，并生成稳定的顶层顺序与子画布顺序。配置检查会读取已连接的输出端口，发现当前重试策略下不可用的分支，或表达式、等待时间和任务参数不符合节点契约时，会给出节点标识、字段路径和错误代码。

遍历集合和条件循环属于容器节点。把它们加入画布时，Playground 会同时创建对应的内部起始节点和一个示例任务，并把起始节点标识写入容器配置。这样新容器从创建起就具备完整作用域，可以继续替换内部任务或增加同一子画布中的连线。

## 交给 CLI 和宿主

DSL 页签展示当前画布生成的完整 JSON 文档，其中保留节点标识、位置、配置、端口连线和父级作用域。复制以后可以运行 `a3s-flow validate` 检查文档版本与结构，再运行 `a3s-flow compile` 查看确定的执行计划。浏览器中的 Playground 不会调用外部工具、读取凭据或启动 Worker。宿主仍需提供节点实现、权限、凭据和幂等策略，生产执行则由 A3S Flow 引擎与 Worker 完成。
